# 边界塌陷判据：把"丢失剖面"做成拐角的分级信号

> 针对《拐点运行图.bmp》的观察："ROI 只切中间、没扫到边界尽头很弯的那段；
> 且边界在塌陷、一部分已经全灰——也许可以用这个判定拐弯处和拐弯的程度。"
> 结论：**方向对，而且比现有的 RMS/两半斜差更贴合拐角的物理**。下面先解释
> 为什么陡坡段一个点都没有（比"ROI 没扫到"更深一层），再把"塌陷度"落成可实现的算法。

---

## 一、这张图里陡坡段为什么一个点都没有（三个机制叠加）

放大后看清了：这个拐角是个**圆顶**——边界区从上方鼓下来，左坡陡到接近竖直，
右侧平缓。十字全落在右侧缓坡，左坡零检测。原因：

1. **"每列一个交点"的模型容不下圆顶**。左坡的列剖面是：蓝路面 → 灰区（圆顶内部）
   → 再穿出去（圆顶上方是图外暗区）——**一列里两次穿越**。现逻辑只取 swing 最大的
   一个，相邻列在"进顶/出顶"之间跳，行值散成一团。
2. **RANSAC 把陡坡点当离群剔了**。竖直的散点团与右侧缓坡线不共线，内点数投票必输。
3. **追踪门补了一刀**：陡坡的行离上一帧拟合线 50~150px，全部 >35px 被拒。

所以不是"ROI 没扫到"（main_new 的窗已经上扩到 row≈12，这段在窗内），
而是**检测模型（单交点 + 直线拟合）表达不了圆顶，且每一层都在主动丢弃它**。
"只检测中间"是结果，不是原因。

---

## 二、"塌陷度"为什么是对的信号

圆顶的本意是：**边界区正在把路面"挤出去"**。左坡列里路面只剩底部一小条甚至为零
——这就是你说的"塌陷成 0、一部分全灰"。它有三个现有判据都没有的优点：

1. **天然分级**：塌陷从 0（整条边界都在）连续涨到 1（路面被挤光），
   拐弯的"程度"直接就是它的值——不需要 15°/6.0 这种硬阈值，也就没有
   half=14.2° vs 15° 那种单帧翻转；
2. **对圆顶/陡坡免疫**：它不靠"每列一个交点 + 直线拟合"表达形状，
   陡坡有没有交点都不影响统计；
3. **零额外开销**：分类用的就是每列已有剖面（19 条的判别通道值），
   一次 get_statistics 都不加。

## 三、算法：按列分四类，统计三个占比

对每列（用该列自己的判别通道剖面）：

```
 crossings = 该列全部强穿越（不再只取 swing 最大者）
 v_top     = 最上 1~2 条的通道值
 v_bot     = 最下 1~2 条的通道值
 若 |v_top - v_bot| < 列内噪声容限:
     若与"有交点列的下端色"同侧 → 该列记【全路面】   # 边界从上方出画
     否则                        → 该列记【全边界区】 # 压到区里
 若 len(crossings) ≥ 2 且相邻穿越间隔 > 2 条     → 该列记【圆顶/非单调】
 否则                                            → 该列记【正常】，取主穿越行
```

帧级三个占比（都是 [0,1] 连续量）：

| 占比 | 含义 | 用途 |
|---|---|---|
| `collapse = 全路面列数 / NCOL` | **塌陷度**：路面被边界区挤掉的比例 | 拐角主信号（本图左坡列全是这一类） |
| `dome = 圆顶列数 / NCOL` | 非单调形状占比 | 最强的单帧拐角证据（现逻辑把它当噪声扔了） |
| `press = 全边界区列数 / NCOL` | 压黄度 | state=3 的方向依据（替代参考色投票） |

- `corner_severity = clamp(collapse + dome, 0, 1)` —— 拐弯程度；
- **输出连续化**：`angle = w·切线 + (1−w)·割线，w = clamp(severity×2, 0, 1)`
  ——不再是"命中/不命中"硬切，half=14.2° 那种抖动从根上消失；
- severity → 1 且 press ≈ 0 → 交界整体出画上方 → state=2；press 涨 → state=3。
  **拐角态与丢线态之间第一次有了连续的过渡带**，不再是非黑即白的切换；
- 全点 RMS / 两半斜差降级为**辅助**（或直接退役）——它们的标定域问题
  （窗口上扩后 0003 误判 6.7、0005 漏判 2.6）也随之消失。

## 四、注意事项（诚实起见）

1. **漂移 vs 拐角的区分**：车向左漂（0003 型）同样会让边界从上方出画、collapse 上涨。
   区分在**空间模式**：拐角的出画是**有梯度的**（一列列依次塌，圆顶列夹杂其中），
   漂移的出画是**整体的**（各列行一起抬、几乎同时出画）。
   落地：看 collapse 的列分布——集中在连续的一段列 = 拐角；均匀散布 = 漂移。
2. **褶皱**：局部塌陷会污染 collapse。追踪门照旧，collapse 再加 2~3 帧中值滤波。
3. **本图的"图外暗区"**：圆顶上方那片深色是地图外的暗背景，不是路面——
   "与下端色同侧"的相对判法天然把它和路面分开（它更像"都不是"），归入
   【全边界区】或【不参与】都行，建议给第四类【无效列】不计入分母。
4. **上扩窗口这次是真需要**：塌陷从顶部开始，row<80 的区域正是信号最强的区——
   之前上扩破坏了 RMS/两半斜差的标定，但塌陷判据是**列内相对量**，
   不依赖绝对标定，上扩对它只赚不亏。

## 五、落地顺序建议

1. 先在 PC 回归里把 7 张图 + 本图按四类分类跑一遍，看 collapse/dome/press
   三个占比能不能分开（直线：collapse≈0、dome=0；本图：collapse/dome 显著）；
2. 判据切换：severity 主判 corner，RMS/两半斜差退役为日志字段；
3. 输出口径：切线/割线按 w 加权；state=2/3 改由 press/collapse 的终值判定；
4. 台架按实车日志复标唯一的新阈值：列内噪声容限（建议直接用该列 own_spread
   的一个比例，延续现有 own_mid 的自参照风格，不引入绝对数）。
