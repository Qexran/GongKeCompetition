## 1. 功能总览

爆爆桶（黑色桶块）对位是一个**独立阶段任务**（对位时车不巡线，2026-10-24 定案）：

```
OpenMV v3.4（检测黑色桶，每帧只报面积最大的一个桶 = 最近/最清晰）
   │  UART 文本帧: "B,<valid>,<cx>,<cy>,<w>,<h>\r\n"   @115200
   │  控制字节: 'B'=起流  'b'=停流  'S'=全停（兼容）
   ▼
树莓派（纯转发，独立线程，~20Hz；与巡线流/靶标流三方互斥）
   │  二进制 COORD 帧 TAG=0x0B: [0x0B][status][cx][cy][w][h] = 10B 定长
   │  单片机命令: "J"=起流（可带毫秒预算 "J,15000"）  "K"=停流
   ▼
单片机 ucRpiBarrelAlign（0x0B 流帧 → cx 偏差 → 纵移闭环）
   │  轴映射与平移射靶同款：相机装 90°，图像 cx ↔ 车体纵移 v_y（vChassisMoveCameraForward）
   ▼
底盘（位置/速度双模式；收敛拍数 + 行程闸 + noprog 闸 + 停稳窗）
```

设计要点（决策记录）：
- **多桶策略 = "OpenMV 挑好再报"**：相机端每帧只报面积最大的一个桶，Pi 不掺和选择（以后换策略只改相机/单片机，帧不变）。
- **检测不用任何 LAB 颜色阈值表**：暗阈值 L<26 一把尺（运行时可调），换场地不用重标颜色。
- **未标定自举**：`bc_cx_aim=0` 时对位步进**只测不改**模式——起流采 3 秒报中位 cx、一格不动（`BKT meas:` 日志行 + 蓝牙遥测 `bucket_err`），解决"瞄准常数永远是 0"的鸡生蛋问题。
- **帧活性靠帧计数**（同 0x05 靶标流语义）：无桶/陈旧也照发，`status bit0` 才是"本拍有没有桶"。

## 2. 帧契约速查

### 2.1 OpenMV → Pi（UART 文本，115200）

```
B,<valid>,<cx>,<cy>,<w>,<h>\r\n
```

| 字段 | 含义 |
|------|------|
| valid | 1=本帧选中了一个桶；0=没找到（坐标为上一帧沿用值，同 L 帧语义） |
| cx/cy | 选中桶 bbox 中心像素坐标（**320×240 QVGA 口径**） |
| w/h | 桶 bbox 宽高 [px]（轴对齐外接框） |

### 2.2 Pi → 单片机（二进制 COORD，TAG=0x0B，~20Hz）

```
DATA = [0x0B][status u8][cx u16 LE][cy u16 LE][w u16 LE][h u16 LE]   共 10 字节
```

| 字段 | 含义 |
|------|------|
| status | bit0 = 1 本拍有桶 / 0 无桶或数据陈旧（流还活着，帧计数照涨）；其余位保留 |
| cx/cy/w/h | 同上；valid=0 时是沿用值 |

示例（valid=1，桶中心 (143,67)、85×54）：
`0B 01 8F 00 43 00 55 00 36 00`

### 2.3 单片机 → Pi 命令

| 命令 | 含义 |
|------|------|
| `"J"` | 爆爆桶坐标流开始（独立线程，0x0B 流帧 ~20Hz）；`"J,<毫秒>"` = 单片机愿意等多久（同阻塞类指令口径，Pi 折算预算） |
| `"K"` | 爆爆桶坐标流停止（幂等） |

### 2.4 Pi → OpenMV 控制字节

| 字节 | 含义 |
|------|------|
| `'B'` | 开始爆爆桶流（发 B 帧；桶模式独占时跳过巡线测量省帧预算） |
| `'b'` | 停止爆爆桶流 |
| `'S'` | 全停（巡线 L 流 + 爆爆桶 B 流） |

### 2.5 与既有协议的兼容性（三端任一端不升级都不炸链路）

- 旧相机收到 `'B'` → 未知控制字节，忽略 → 流起不来，单片机帧计数停涨自动冻结（安全退化）。
- 旧 Pi 收到 `"J"` → 未知指令打一行 WARN。
- 旧单片机收到 0x0B 帧 → 没有该分支，10B 帧落进通用 last-packet 分支（不会误触发什么，等待方靠超时长鸣退出）。
- **旧固件发裸 "J" 没问题**；新 Pi 收到未知 'B' 字节进 openmv 串口时也只是忽略。

对位原语 `ucRpiBarrelAlign(timeout, keep_res)` 的流程（照抄平移射靶精调环，跳过二维码/粗调/双相机段）：

```
① 起流：发 "J"（等链路，失败直接返回，不发 "K"）
② 等停稳：连续 3 个新帧桶 cx 变化 < 4px（上限 800ms，到点照常往下走）
③ 若 bc_cx_aim=0（未标定）→ 只测模式：采 3s 报中位 cx（"BKT meas:" 行），停流返回 0
④ 闭环（每拍 bc_ctrl_ms=180ms）：
     中止位 → 帧新鲜度（停涨 > bc_stale_ms 冻结；> 2× 且限速到 → 重发 "J" 自愈）
     → 取桶帧（无桶continue）→ fDpx = cx − bc_cx_aim（swap 选轴）
     → 收敛判据（|fDpx| < bc_conv_px 连续 bc_conv_ticks 拍，排在 noprog 之前）
     → 偏差mm = fDpx × bc_px_to_mm × bc_sign → 位置模式（钳 ±bc_step_mm，
       阻塞 vChassisMoveCameraForward 纵移）/ 速度模式（rpm 连续修，零速带顶格）
     → 最小出力门 bc_db_mm / 行程闸 bc_travel_mm / noprog 闸
⑤ 无论成败发 "K" 停流（速度模式先显式停车）
⑥ keep_res=1 → 累计纵移折世界系记「路径残留偏移」
⑦ 收官：BKT ok / fail: noprog / fail: travel / abort / fail: timeout
```

## 5. 现场标定流程（预设 46「测试爆爆桶对位」，可重入）

**前提**：车摆到"正对爆爆桶、即推桶臂/车头动作的起始位姿"。

| 步骤 | 操作 | 看什么 |
|------|------|--------|
| ① 读瞄准列 | 不填 bc_cx_aim（保持 0）→ 跑一次预设 46 | `BKT meas: cx=143 cy=67 w=85 h=54 n=..  <-- 填进 bc_cx_aim`；或蓝牙遥测 bucket_err 稳定值。把 cx 填进蓝牙「爆爆桶」组 `bc_cx_aim` |
| ② 定方向 | 前后挪车 ±20mm，各跑一次 | `bucket_err` 变大 = bc_sign 对；单调变小也正常（在逼近）；**跑起来后偏差越来越远 = bc_sign 反了，改 -1** |
| ③ 标比例尺 | 记下挪动的真实 mm ÷ bucket_err 变化 px | 填 `bc_px_to_mm`（出厂 0.8 是**占位值**，必须实测重标） |

标定完把终值回写 `app_config.h` 的 `BUCKET_ALIGN_*` 固化（同 tc_* 那套纪律）。

## 7. 排障指南

| 症状 | 先查什么 |
|------|----------|
| 跑对位步秒退、日志 `BKT meas: ... n=0` 或一直 settle | 相机没升级到 v3.4（发 'B' 无回应——openmv_serial 会打"已触发爆爆桶流('B')但 Ns 无 B 帧"）；或 OpenMV 未上电/插错口 |
| Pi 日志 bad_lines 猛涨 | 相机在发 B 帧但 Pi 解析器是旧版（部署顺序错了：先 Pi 后相机） |
| 单片机帧计数停涨、冻结不动 | Pi 侧流线程死了（看 `[爆爆桶流]` 日志与 fps）——正常时 `BC_MAX_S=30s` 会自退、单片机 2×stale 后自愈重发 "J" |
| 回放模式命中率高、实时不命中 | 实时帧过了 `lens_corr`（回放样本是已校正的 'P' 帧）——用 'P' 拍现场帧喂回放对比；多为光照差异，调 'N' |
| 桶检到了但 cx 抖 ±8px | 走的是瓦片兜底路径（`探no`）——正常，列细扫已压到 ±2px；仍抖则 bc_conv_px 放大到 ≥8 |
| 桶贴黑界线时 valid=0 | 粘连成大块被剔线门杀——宁缺勿假是有意行为；调 ROI 上沿避开线，或等分榜现场给桶前留出地面 |
| 偏差单调变大 | bc_sign 反了 |
| 原地振荡 | 降 bc_kp_scale 或加大 bc_db_mm |
| `BKT fail: noprog` | 方向反 / 比例尺离谱 / 桶被顶住 —— 看 BKT n= 过程串的 d 走向 |
